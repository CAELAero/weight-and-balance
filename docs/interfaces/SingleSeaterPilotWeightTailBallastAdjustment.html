    Interface SingleSeaterPilotWeightTailBallastAdjustment

    Modified pilot weights based on the amount of ballast in the tail. Note that in aircraft that have 2 tail ballast tanks for CG adjustment, this is the total amount of water between both tanks. It is up to the pilot to decide how to distribute the weight between those tanks.

    Note that this is not used for tail batteries that might be removable.
