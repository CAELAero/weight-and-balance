    Interface WeightAndBalanceDatum

    Datum is defined by type certificate, not per aircraft type. Note that to uniquely identify what calculation is to be done, 3 parts will uniquely identify the aircraft - the type certification ID, the JAR22 category, and also a wingspan. Most modern aircraft will have multiple wingspan options, which can, sometimes, lead to different datum requirements particularly dry or all up weights.
